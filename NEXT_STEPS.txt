STEP 2: Get Google Web Client ID (3 minutes)
───────────────────────────────────────────────────────────────────────────────

1. Go to: https://console.cloud.google.com
2. Select your Firebase project
3. Click: APIs & Services
4. Click: Credentials
5. Find: "Web client" (not Android)
6. Copy the long ID (ends with .apps.googleusercontent.com)
7. Open file: src/nativeGoogleSignIn.js
8. Find line 27 that says:
     clientId: '351985375859-abcdefghijklmnopqrstuvwxyz.apps.googleusercontent.com',
9. Replace with your copied ID

EXAMPLE:
Before: clientId: '351985375859-abc...xyz.apps.googleusercontent.com',
After:  clientId: '123456789-def...uvw.apps.googleusercontent.com',

───────────────────────────────────────────────────────────────────────────────

  AB:CD:EF:12:34:56:78:90:AB:CD:EF:12:34:56:78:90:AB:CD:EF:12

STEP 4: Add SHA-1 to Firebase
───────────────────────────────────────────────────────────────────────────────

1. Go to: https://console.firebase.google.com
2. Select your project
3. Click: Project Settings
4. Scroll to: "Your apps" section
5. Click: Your Android app (com.police.case)
6. Scroll down to: "SHA certificate fingerprints"
7. Click: "Add fingerprint"
8. Paste your SHA-1 from Step 3
9. Click: Save

💡 QUICK TIPS:

  • npm install not working?
    → Check you're in C:\Users\gurup\police\crimetrack-app folder
    → Try: npm cache clean --force && npm install

  • npm run get-sha1 not working?
    → Install Java first: https://www.oracle.com/java/
    → Or install Android Studio (includes Java)

  • Google popup not showing?
    → Disable popup blocker for localhost:5174
    → Check browser console (F12) for errors

  • Email not arriving?
    → Check spam folder
    → Check emailService.js has right credentials
