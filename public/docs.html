User Manual & Documentation

Welcome to CrimeTrack Pro, a highly-secure, offline-first tracking database designed specifically for law enforcement professionals. This documentation serves as your comprehensive, detailed guide to setting up and using the application effectively.

Figure 1: The main operational dashboard.

1. Cloud Accounts & Profiles

CrimeTrack Pro is equipped with a secure, cloud-based authentication system powered by Firebase. This ensures that your identity is verified and your data is safe.

Signing Up and Logging In

  • Google Sign-In: Instantly log in using your official Google account.
  • Email/Password: Create an account with your email. You will receive a verification link that you must click before accessing the app.

Managing Your Officer Profile

Once logged in, you must complete your Officer Profile before accessing the Dashboard.

  • Go to the Profile tab to view your credentials.
  • Click Edit Profile to update your Name, Police Station, and Profile Photo.
  • Cloud Synchronization: Your profile data is safely stored in the cloud. You can log into CrimeTrack Pro on any device and your details will instantly sync.

2. App Security

Security is the foundation of CrimeTrack Pro. Officers sign in with verified Firebase credentials and their registered police profile before live tools unlock.

CRITICAL WARNING
Keep Firebase access and organization credentials protected. Local database encryption depends on the deployment settings configured by your administrator.

Authentication Steps:

  1. Register officer: Create an account and complete the police profile fields.
  2. Verify email: Confirm the Firebase verification link before using live mode.
  3. Use demo carefully: Demo mode previews the UI but keeps record editing, exports, operations, and sync tools restricted.

2. Dashboard Overview

The Home Dashboard is your primary command center. It provides at-a-glance analytics and quick access to core tools.

Figure 2: Real-time pie charts and activity alerts.
  • Alert Center: A scrolling marquee at the top highlights individuals marked as "HIGH" or "EXTREME" threats based on pending cases and affiliations.
  • Connection Hub: Located below the alerts, this panel shows the live status of your 3 data layers: Local Storage, Google Sheets, and Custom Database.
  • Data Source Selector: A dropdown allowing you to easily switch between databases. Clicking "Load Data" pulls the latest records from the cloud into your view.

4. Adding & Editing Records

CrimeTrack features an extensive, highly detailed form for suspect entry.

How to add a suspect:

  1. Tap the large blue + (Plus) button located in the center of the bottom navigation bar.
  2. You will be presented with a tabbed form:
    • Demographics: Name, Photo upload, Address, Age, Sex, Religion.
    • Legal Details: FIR Number, Session Number, Pending Cases, Police Station Jurisdiction.
    • Criminal Profile: Current Doings, Status (Active, Arrested, Absconding, Deceased), Gang Leader, Hideouts, Area of Operation.
  3. Save Destination: Before saving, use the dropdown at the very bottom to explicitly choose where this record gets stored (e.g., Local Storage only, or push directly to Google Sheets).
Instant Image Storage Engine
When you upload a suspect's photo or update your officer profile photo, the app automatically compresses the image into a highly-optimized, lightweight format (Base64) and saves it directly into the database row! You no longer need to rely on external file storage like Google Drive. It is completely seamless, saves space, and works instantly across Local Storage and Google Sheets.

5. AI Face Scanning

The crown jewel of CrimeTrack Pro is its integrated, completely offline Artificial Intelligence facial recognition engine.

  1. Tap the Scan Face to Search button on the Dashboard.
  2. You can either upload an existing photo from your gallery or use the live camera.
  3. The system will detect the face in the image, extract a secure biometric signature, and compare it against thousands of records in your database in milliseconds.
  4. Matches are returned with a percentage confidence score.
Privacy Focused Architecture
Face matching happens 100% locally on your device hardware. Images are never uploaded to the cloud for processing, ensuring compliance with strict privacy and security protocols.

6. Secure Operations Chat

The Operations tab allows officers to communicate securely in real-time during live operations. It uses military-grade Peer-to-Peer (P2P) encryption, meaning messages are sent directly between devices and never stored on any server.

How to create or join an Operation:

  1. Tap the Operations icon on the bottom navigation bar (heartbeat icon).
  2. There is no "Create" button. Rooms are generated dynamically. Simply invent a Room ID (e.g., STING-01) and a Secret Key (e.g., DeltaForce99).
  3. Share this exact Room ID and Secret Key with your team members via secure channels.
  4. When your team members enter the exact same ID and Key, they will instantly join the encrypted room.
  5. If someone enters the wrong Secret Key, they will not be able to read the messages in the room (they will appear as scrambled gibberish).
Ephemeral Data
Because Operations chat is strictly Peer-to-Peer, if all officers leave the room, the chat history is permanently destroyed. Do not use this feature for long-term record keeping.

8. Google Sheets Integration (Setup)

You can use a completely free Google Sheet as your cloud database without needing any paid Google Cloud APIs. Follow these specific steps to configure it.

Step-by-step Setup:

  1. Go to Google Sheets on your desktop and create a blank spreadsheet. Name it "CrimeTrack Database".
  2. In the menu bar, click Extensions > Apps Script.
  3. Delete any code in the editor, and paste the official CrimeTrack integration code provided below: 
var API_SECRET = "CHANGE_ME"; // Set your secret key here!

function authenticate_(secret) {
  if (API_SECRET && API_SECRET !== "CHANGE_ME" && secret !== API_SECRET) {
    throw new Error("Unauthorized: Invalid API Secret Key");
  }
}

function doGet(e) { 
  try {
    authenticate_(e.parameter && e.parameter.secret);
    var action = (e.parameter && e.parameter.action) || 'read';
    if (action === 'read_logs') return jsonResponse(handleReadLogs_());
    return jsonResponse(handleRead_()); 
  } catch (err) {
    return jsonResponse({ status: 'error', message: String(err) });
  }
}

function doPost(e) {
  try {
    var body = {};
    if (e.postData && e.postData.contents) body = JSON.parse(e.postData.contents);
    authenticate_(body.secret || (e.parameter && e.parameter.secret));

    var action = (body.action || (e.parameter && e.parameter.action) || 'read').toLowerCase();

    if (action === 'read') return jsonResponse(handleRead_());
    if (action === 'read_logs') return jsonResponse(handleReadLogs_());
    if (action === 'write' && body.records) return jsonResponse(handleWrite_(body.records));
    if (action === 'log' && body.payload) return jsonResponse(handleLog_(body.payload));
    
    return jsonResponse({ status: 'error', message: 'Unknown action.' });
  } catch (err) {
    return jsonResponse({ status: 'error', message: String(err) });
  }
}

function handleRead_() {
  var sheet = getSheet_('Sheet1');
  var data = sheet.getDataRange().getValues();
  if (data.length < 2) return { status: 'success', records: [], count: 0 };
  
  var keys = data[0];
  var records = [];
  for (var r = 1; r < data.length; r++) {
    var rec = {};
    for (var k = 0; k < keys.length; k++) {
      rec[keys[k]] = data[r][k] != null ? String(data[r][k]) : '';
    }
    if (rec.id || rec.name || rec.encryptedData) records.push(rec);
  }
  return { status: 'success', records: records, count: records.length };
}

function handleWrite_(records) {
  var sheet = getSheet_('Sheet1');
  sheet.clear();
  if (records.length === 0) return { status: 'success', message: 'Cleared records' };
  
  var keys = Object.keys(records[0]);
  var rows = [keys];
  for (var i = 0; i < records.length; i++) {
    var row = [];
    for (var k = 0; k < keys.length; k++) {
      var v = records[i][keys[k]];
      if (typeof v === 'object') v = JSON.stringify(v);
      if (String(v).length > 49000) v = String(v).substring(0, 49000);
      row.push(v != null ? v : '');
    }
    rows.push(row);
  }
  sheet.getRange(1, 1, rows.length, keys.length).setValues(rows);
  return { status: 'success', message: 'Saved ' + records.length + ' records', count: records.length };
}

function handleLog_(payload) {
  var sheet = getSheet_('Logs', true);
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(['Timestamp', 'Officer ID', 'Event', 'Details']);
    sheet.setFrozenRows(1);
  }
  sheet.appendRow([payload.timestamp, payload.officerId, payload.event, payload.details]);
  return { status: 'success', message: 'Log appended' };
}

function handleReadLogs_() {
  var sheet = getSheet_('Logs', false);
  if (!sheet) return { status: 'success', logs: [] };
  var data = sheet.getDataRange().getValues();
  if (data.length < 2) return { status: 'success', logs: [] };
  
  var logs = [];
  var start = Math.max(1, data.length - 20);
  for (var r = start; r < data.length; r++) {
    logs.push({
      timestamp: data[r][0],
      officerId: data[r][1],
      event: data[r][2],
      details: data[r][3]
    });
  }
  return { status: 'success', logs: logs };
}

function getSheet_(name, createIfMissing) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName(name);
  if (!sheet && createIfMissing) sheet = ss.insertSheet(name);
  if (!sheet) sheet = ss.getActiveSheet();
  return sheet;
}

function jsonResponse(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON);
}

Troubleshooting: CORS Errors
If you get a "blocked by CORS policy" error when trying to sync or migrate, it means Google is trying to ask you for permission in the background, but it can't. To fix this:
  1. Go back to your Apps Script Editor.
  2. Click Run at the top to trigger the "Authorization Required" popup, and accept it (Advanced -> Go to unsafe -> Allow).
  3. You MUST create a New Deployment. Do not just click Save. Click Deploy > New Deployment.
  4. Ensure it is set to Execute as: Me and Who has access: Anyone.
  5. CRITICAL: Google generates a completely NEW URL for every "New Deployment". You must copy this new URL, go back to the CrimeTrack Settings, delete the old URL, and paste the new one. If you don't update the URL in Settings, the CORS error will persist!

9. Custom Database Setup (MySQL/MongoDB)

Because CrimeTrack Pro is a secure frontend application, it cannot connect directly to MySQL or MongoDB for security reasons. Instead, you need to run a small Node.js server.

We provide two scripts inside the app's public folder: backend-mysql.js and backend-mongo.js. These scripts automatically create your databases and tables/collections when you run them!

MySQL Setup Steps

  1. Install Node.js on your server.
  2. Copy the code below into a file named server.js (or use backend-mysql.js from the public folder).
  3. Install the required packages: npm install express cors mysql2
  4. Run the server: node server.js
  5. In CrimeTrack Pro, go to Settings > Custom Database API, select MySQL, and paste your server URL (e.g. http://localhost:3000/api/records).
// MySQL Server Setup (server.js)
const express = require('express');
const mysql = require('mysql2/promise');
const cors = require('cors');
const app = express();
app.use(cors()); app.use(express.json({ limit: '50mb' }));

const dbConfig = { host: 'localhost', user: 'root', password: '', database: 'crimetrack_db' };
let pool;

async function initDatabase() {
  const conn = await mysql.createConnection({ host: dbConfig.host, user: dbConfig.user, password: dbConfig.password });
  await conn.query(`CREATE DATABASE IF NOT EXISTS \`${dbConfig.database}\`;`);
  await conn.end();
  pool = mysql.createPool(dbConfig);
  await pool.query(`CREATE TABLE IF NOT EXISTS records ( id VARCHAR(50) PRIMARY KEY, name VARCHAR(255), photo LONGTEXT, data JSON )`);
}
initDatabase();

app.get('/api/records', async (req, res) => {
  const [rows] = await pool.query('SELECT * FROM records');
  res.json(rows);
});
app.post('/api/records', async (req, res) => {
  // Handle inserts here
  res.json({ success: true });
});
app.listen(3000, () => console.log('MySQL API running on port 3000'));

MongoDB Setup Steps

  1. Install Node.js and MongoDB on your server.
  2. Copy the code below into a file named server.js (or use backend-mongo.js from the public folder).
  3. Install the required packages: npm install express cors mongodb
  4. Run the server: node server.js
// MongoDB Server Setup (server.js)
const express = require('express');
const { MongoClient } = require('mongodb');
const cors = require('cors');
const app = express();
app.use(cors()); app.use(express.json({ limit: '50mb' }));

let db;
async function initDatabase() {
  const client = new MongoClient('mongodb://localhost:27017');
  await client.connect();
  db = client.db('crimetrack_db');
}
initDatabase();

app.get('/api/records', async (req, res) => {
  const records = await db.collection('records').find({}).toArray();
  res.json(records.map(r => { delete r._id; return r; }));
});
app.post('/api/records', async (req, res) => {
  const records = req.body;
  await db.collection('records').deleteMany({});
  if (records.length > 0) await db.collection('records').insertMany(records);
  res.json({ success: true });
});
app.listen(3000, () => console.log('MongoDB API running on port 3000'));

10. Cross-Database Migration

Just added to CrimeTrack Pro: the ability to seamlessly migrate bulk data between backends.

If you have been working entirely on Local Storage and just set up your Google Sheet, you can instantly move all your data.

  1. Go to the Settings tab.
  2. Locate the Cross-Database Migration panel.
  3. Set Migrate From to "Local Storage".
  4. Set Migrate To to "Google Sheets".
  5. Click Start Migration. The system will safely push all your local records into the cloud sheet.

11. Backup and Restore

Data loss is unacceptable. CrimeTrack Pro features robust physical backup tools.

  • Backup ZIP: Available on the Home Dashboard under "Offline Tools". This generates a highly compressed .zip file containing your JSON database and all Base64 images as physical .jpg files. Save this to a secure thumb drive.
  • Restore ZIP: Simply select your generated ZIP file to instantly rehydrate the app with your records and photos.
  • Export Excel: Downloads a clean .xlsx file containing all text metadata suitable for court reports and physical printing.

CrimeTrack is no longer just for police. It has been upgraded into a monolithic "Government OS" that unifies 12 departments into a single application. You can access all modules via the Government Services Hub (GovModuleLauncher) on the Home screen.
